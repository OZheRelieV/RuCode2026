# Подбери страховку

## Описание задачи

Крупная компания расширяет линейку страховых продуктов и выводит в продажу страховку «Защищённый смартфон» — в случае повреждения экрана застрахованного телефона страховая компания компенсирует затраты на его ремонт или замену. Каким клиентам стоит предложить новую страховку, чтобы добиться максимальной конверсии в продажу? Помогите определить клиентов, которые с наибольшей вероятностью приобретут этот страховой продукт.

## Задание

Ваша задача найти клиентов, которые с наибольшей вероятностью купят новую страховку. Для этого вам предоставлен набор данных, содержащий данные о клиентах, которые уже приобрели этот страховой продукт.

## Метрика

F1

## Решение

1. Было рассмотрено более 250 комбинаций моделей и препроцессоров данных

|preprocessor|values|
|-|-|
|imputer|none/constant|
|scaler|none/standard|
|categorical encoder|OHE(one hot encoder)/LE(laber encoder)|

2. Отобрано более 100 успешных комбинаций, которые не упали с ошибкой
3. Топ-10 лучших комбинаций

|№|model_name|scaler|imputer|categorical encoder|oof_f1|global_f1|
|-|-|-|-|-|-|-|
|1|tabdpt|standard|median|LE|0.96355498|0.96091371|
|2|tabdpt|none|median|LE|0.96355498|0.96091371|
|3|tabicl|none|none|none|0.96330836|0.96140173|
|4|realmlp|none|median|OHE|0.96314474|0.95973664|
|5|tabdpt|standard|none|LE|0.96311736|0.96132316|
|6|tabdpt|none|none|LE|0.96311736|0.96132316|
|7|tabicl|standard|none|none|0.96311621|0.96134283|
|8|tabdpt|standard|median|OHE|0.96220195|0.96012192|
|9|tabdpt|none|median|OHE|0.96220195|0.96012192|
|10|realmlp|none|median|LE|0.96195348|0.95756365|

Топ моделей получился такой: `tabdpt`, `tabicl`, `realmlp`.

4. В качестве базового решения была выбрана модель - `tabdpt`, показавшая наибольшую метрику на oof
5. Для согласованности метрик до обучения и подбора гиперпараметров (HPO) были получены фолды с `StratifiedKFold(n_splits=5)`
5. Для зафиксированной модели был проведён подбор гиперпараметров HPO (`best_params`)
6. C `best_params` были обучены 5 моделей. Внутри каждого фолда записывались фолдовые значения порога для классификации. После обучения 5 моделей были рассчитаны веса, необходимые для взвешенного усреднения (WA) предсказаний на тестовом наборе
7. После WA итоговое предсказание на тесте формируется путём сравнения с порогом, равным 0.5

## Запуск

1. Склонировать [репозиторий](https://github.com/OZheRelieV/RuCode2026):

> git clone --branch b_task --single-branch https://github.com/OZheRelieV/RuCode2026.git b_task

2. Перейти в папку

> cd b_task

3. Скачать данные (train & public test): [Ссылка на данные](https://drive.google.com/file/d/1EpLYYyaTOGmD3mq5ECtyLSrcgB6niDNt/view)

3.1 Скачать данные (private test): [Ссылка на данные](https://drive.google.com/drive/folders/1MYRQ6uLT8fVjr7YUrIbDWrzyVfNI0diD)

4. Создать папку `data/`

> mkdir data

5. Данные при необходимости распаковать и положить в `data/`

6. **Для дальнейшей работы нужен uv**. Создать виртуальное окружение

> uv sync

6. Активировать виртуальное окружение

> source .venv/bin/activate

7. Запустить скрипт формирования фолдов

> python gen_folds.py

8. Запустить скрипты по очереди

> 1. python tabdpt_hpo.py  
> 2. python tabdpt_train.py

9. Запустить инференс на тестовом наборе

9.1 Инференс на публичном тесте:
> python tabdpt_inference.py --test data/public_test.csv --part public

9.2 Инференс на приватном тесте:
> python tabdpt_inference.py --test data/private_test.csv --part private

> **P.S**  
> **Обязательно укажите `part`. Этот флаг необходим для корректной обработки данных**  
> **В команде запуска обязательно выбрать один из вариантов public_test/private_test**

10. В папке `subs/` будет файл `submission_tabdpt_{args.part}.csv`

> `args.part` - это флаг, указывающий с каким набором идёт работа
